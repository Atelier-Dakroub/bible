# Tools

This page tells you about the Tools panel and each of its four tabs: Reading, Marks, Table and Saved.

## The Tools panel

Tap **Tools** on the rail. The panel opens beside the rail. It has four tabs at the top: **Reading**, **Marks**, **Table** and **Saved**. Tap a tab to show it. With the keyboard, use the arrow keys to move from tab to tab.

- A docked panel closes when you tap outside it, or when you press <kbd>Escape</kbd>. A resting palm does not close it.
- A floating panel stays open until you close it with its **×**.

At the bottom of the panel are two links: **The guide** opens this guide, and **Credits** opens the page of the sources of the data. The table stays as it is, and comes back when you return.

## Reading

### The text

These settings change how the text looks. The browser keeps them for the next visit.

| Setting | Choices |
| --- | --- |
| **Theme** | **Day**, **Night**, or **Computer**, which follows the light or dark setting of the computer |
| **Paper** | **Bright**, **Soft** or **Lamp**. Soft and Lamp are for a dim room. |
| **Text size** | **1** (the smallest) to **5** (the largest) |
| **Line spacing** | **Compact**, **Normal** or **Loose** |
| **The text shows** | **Red letters** (the words of Christ in red), **Numbers** (verse numbers) and **Initials** (a large letter at the start of a chapter). Each is on or off. |
| **Layout** | **Paragraphs** or **Verses** |

Each choice is a tile that shows what it does. The tile that is chosen has a lapis ring.

### Read aloud

| Setting | Choices |
| --- | --- |
| **Voice** | **Recording** or **This device**. Only in a copy of the app that has recordings. |
| **This device's voice** | **Automatic**, or a voice of this device, for English, Hebrew and Greek. **Try** reads a verse in it. |
| **Speed** | **0.8×**, **1×**, **1.15×**, **1.3×** or **1.5×** |

Where there is no recording of a passage, this device's voice reads it. See [Listen and watch](/guide/listen-watch), and [Better voices](/guide/listen-watch#better-voices) to add voices to your device.

## Marks

### New highlights

**Style** chooses the style of the next highlight that you make: **Filled**, **Underlined** or **Boxed**. See [Cards](/guide/cards#highlights).

### Mark on every card

A mark shows on every card on the table, also on cards that you put down later. Tick a box to add a mark, and tick it again to take the mark off:

- **Words of Christ**
- **Words the translators supplied**
- **The divine name**
- **Every person**
- **Every place**
- **Every group**

To mark one word, person or place, tap it on a card. Then tap **Mark it on every card** in the search panel.

### Marks on now

This list shows the marks that are on. Each mark has a style of its own: a bar over the words, dots under them, a dashed box or a wavy line. So the marks of several rules on one word all show.

- **Style** gives the mark the next style.
- **Remove** takes the mark off.

The table keeps its marks with it.

## Table

### Cards

**Snap**: when it is on, a card that you move lines up with the other cards. Hold <kbd>Command</kbd> or <kbd>Control</kbd> while you drag to move a card freely. See [Start here](/guide/start#snapping).

### Tools and panels

| Setting | Choices |
| --- | --- |
| **Rail on the** | **Left**, **Right**, **Top** or **Bottom** |
| **Size of the tools** | **Small**, **Medium** or **Large**. This changes the rail and the panels only. |

### The whole screen

**Interface** changes the size of everything on this device, the cards too: **S**, **M**, **L**, **XL** or **Far**. **M** is the size that the app chooses for this kind of screen. **Far** is for a wall that you see from across the room. At **Far**, the arrow keys move from card to card. See [Keys and touch](/guide/keys-touch#the-wall).

The text size of **Reading** is on top of this size.

### On-screen keyboard

This setting chooses when the app's own keyboard shows:

- **Automatic**: for a finger on a large touch screen with no keyboard near. Never on a phone or a tablet.
- **Always**
- **Never**

See [Keys and touch](/guide/keys-touch#the-app-s-on-screen-keyboard).

> On a phone, the rail is always at the bottom and the app's keyboard never shows. So the **Table** tab shows only **Snap**, **Size of the tools** and **Interface**. **Far** is not on a phone.

## Saved

The browser keeps the table on show for you. This tab keeps tables under a name, and in files.

### This table

1. Type a name in the **Name** field.
2. Tap **Save**.

When you change a saved table, save it again to keep the changes under its name.

When you save a table, the app asks the browser to keep its storage. Most browsers decide for themselves. Firefox asks you. If the browser does not agree, it can clear your saved tables when the device needs space. Then the app tells you, and a file is the safe copy.

### Saved tables

This list shows each saved table, with the time when you saved it.

- Tap the name of a table to open it.
- Tap **Delete**, then tap it again (**Delete?**) to delete the table. You cannot undo this.

Undo takes back the opening of a table in one step.

### Files

| Button | What it does |
| --- | --- |
| **Save to a file** | Saves the table to a file on this device. |
| **Open a file** | Opens a table from a file that you saved. |
| **Notes as Markdown** | Saves all the notes of the table to a Markdown file. See [Notes](/guide/notes#notes-as-markdown). |

Use a file to move a table to another device, or to keep a copy.

### Start again

**New table** clears the table. The table on show goes, so save it first to keep it. Undo brings the old table back.
